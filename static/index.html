Frontend: HTML, CSS, and JavaScript now only render the board, charts, and dashboard.

Backend: A FastAPI service owns the snake environment, replay buffer, and DQN training loop.

Flow: The browser calls the API every frame, receives the latest board state, and redraws the scene.

Why this split? Training logic is now reusable from Python and no longer tied to one HTML file.

الواجهة: ملفات HTML وCSS وJavaScript بقت مسؤولة عن الرسم والعرض فقط.

الباك إند: خدمة FastAPI بقت شايلة بيئة اللعبة والـ replay buffer ومنطق تدريب الـ DQN.

طريقة العمل: المتصفح يرسل طلب كل فريم، ويرجع له آخر حالة للعبة ثم يعيد رسمها.

فايدة الفصل: منطق التعلم بقى مستقل في بايثون وسهل تطويره أو استبداله لاحقا.
